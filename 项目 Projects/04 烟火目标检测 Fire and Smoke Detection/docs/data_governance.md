# Data governance

The dataset is not published in this repository. The archived clean five-class collection contains 22,899 images and matching labels, but source licenses and redistribution permissions are not fully resolved.

D-Fire is recorded as a source for fire/smoke material, while its license still requires confirmation. Other merged sources, including any video-derived material, need source-level provenance and redistribution review before public release. The presence of person and vehicle classes introduces potential privacy concerns such as faces, license plates, and surveillance scenes.

The private audit found 40 exact duplicate-file groups containing 10,451 file copies. Possible adjacent video frames, scene overlap across splits, and split leakage have not been systematically ruled out. The current validation records must not be treated as a leakage-free benchmark.

This repository releases only aggregate and per-epoch statistics. It includes no images, labels, videos, datasets, weights, or raw annotations.
