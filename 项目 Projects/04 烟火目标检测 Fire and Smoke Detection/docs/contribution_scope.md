# Contribution scope

## Confirmed from the archive

The archive contains a workflow with data-conversion records, three-class baselines, five-class Standard and From3Class experiments, configuration snapshots, validation CSV files, model artifacts, and report materials. It identifies YOLO11-related training configurations and records D-Fire as one fire/smoke data source.

## Public reconstruction completed for this portfolio

For this portfolio version, the archived metric CSVs were rechecked, best-versus-final metrics were separated, sanitized public result tables were derived, and figure-rebuild code plus evidence-boundary documentation were written. These new materials do not modify or replace the archived experiment artifacts.

## Third-party components

YOLO11/Ultralytics-related software, pretrained checkpoints, D-Fire, and any other merged data are third-party or externally sourced components unless independently documented otherwise. Their exact licenses and publication permissions remain outside this repository's confirmed scope.

## Items not independently confirmed

The archive alone does not prove who performed each collection, labeling, cleaning, split, training, tuning, or reporting step. It also does not fully establish environment versions, dataset redistribution rights, or permission to publish derived weights. This repository therefore uses neutral language such as “the archived project contains” and “the audited runs record.”
