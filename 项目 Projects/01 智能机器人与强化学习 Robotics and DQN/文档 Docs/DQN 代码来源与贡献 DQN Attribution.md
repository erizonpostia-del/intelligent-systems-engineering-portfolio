# DQN attribution

I independently completed the DQN implementation and experimental workflow for the course project. The instructor-confirmed boundary excludes tutorial material and third-party software.

The public source subset contains my DQN components, including network definitions, replay buffer, observation wrappers, algorithm variants, and extension utilities. Flappy Bird Gymnasium provides the environment. Gymnasium, PyTorch, and NumPy are third-party dependencies. Double DQN and Dueling DQN are established methods used for controlled comparison, not novel algorithms claimed by this project.

Model weights, original raw runs, and private course materials are not distributed.
