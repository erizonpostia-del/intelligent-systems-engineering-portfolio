# Evidence guide

This page points readers to the evidence behind the public claims. The detailed private claim matrix is not part of the public portfolio.

| Area | Claim supported | Public evidence | Boundary |
|---|---|---|---|
| ROS1 simulation | Nine-goal navigation in Gazebo | source subset, redacted terminal image, result summary | simulation only |
| Team TurtleBot deployment | Team-based physical goal-point movement context | redacted Navigation2 image and contribution record | not a continuous autonomous-navigation proof |
| Historical DQN | Archived 2000-episode Double Dueling DQN result | evaluation and training summaries | historical archived result, not the main current conclusion |
| Standardized DQN re-evaluation | 100-episode re-evaluation of the saved historical checkpoint | evaluation summary and final report | distinct from the archived evaluation |
| Controlled DQN ablations | observation, budget, and algorithm comparisons | CSV summaries, configs, and figures | configuration-specific descriptive evidence |

The public result files are machine-readable derivatives. The original raw runs, private logs, original videos, course documents, and model weights remain private.
