# Project notes

## Data and results

The scripts generate a simulated regression dataset with `make_regression` each time they run. The repository does not include an external dataset. The reported figures and CSV files come from the verified run described in [reproducibility.md](reproducibility.md).

## Public scope

This repository contains the two standalone Python scripts, generated results, figures, and reader-facing documentation. It does not include course materials, course notebooks, assignment or submission files, private reports, or course subprojects whose authorship is not confirmed.

## Interpretation

The project uses one simulated configuration to compare regularization and evaluation workflows. Its results are useful for discussing validation-based alpha selection, coefficient shrinkage, and fold-to-fold variation. They are not evidence of real-world model performance.
