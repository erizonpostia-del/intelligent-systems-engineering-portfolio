# Contribution scope

## Confirmed from the archive

The archive contains a workflow with data-conversion records, three-class baselines, five-class Standard and From3Class experiments, configuration snapshots, validation CSV files, model artifacts, and report materials. It identifies YOLO11-related training configurations and records D-Fire as one fire/smoke data source.

Supplementary command-history evidence confirms archive analysis, preparation of data and container-build packages, upload and download operations, five-class server-export extraction, SHA-256 verification, a local CPU smoke run, and local label and split checks. Server account history also records image construction, GPU Docker container starts, dataset/run inspection, and result packaging. These records establish that the actions occurred at account level; shared access and the absent inner-container transcript mean they do not assign every remote training command or monitoring action to one person.

## Public reconstruction completed for this portfolio

For this portfolio version, the archived metric CSVs were rechecked, best-versus-final metrics were separated, validation results were organized into sanitized public tables, and figure-rebuild code plus evidence-boundary documentation were written. These new materials do not modify or replace the archived experiment artifacts.

## Third-party components

YOLO11/Ultralytics-related software, pretrained checkpoints, D-Fire, and any other merged data are third-party or externally sourced components unless independently documented otherwise. Their exact licenses and publication permissions remain outside this repository's confirmed scope.

## Items not independently confirmed

The archive does not independently prove original dataset collection, the annotation process, complete training-implementation ownership, or who started and monitored every remote run. It also does not fully establish dataset redistribution rights or permission to publish derived weights. This repository therefore uses neutral language such as “the archived project contains” and “the audited runs record.”
