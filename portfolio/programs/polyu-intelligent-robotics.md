# PolyU — MSc Intelligent Robotics Engineering

## Priority portfolio items

1. [01 — Robotics & DQN](../../projects/01-robotics-dqn/) — covers ROS, Gazebo, LiDAR, waypoint navigation, TurtleBot3 integration, and DQN control evaluation.
2. [04 — Fire & Smoke Detection](../../projects/04-fire-smoke-detection/) — shows the perception side of intelligent-system engineering, including difficult-target analysis.
3. [02 — Machine Learning Evaluation](../../projects/02-ml-evaluation/) — shows reproducible model-selection and evaluation practice.

The sequence connects robot integration, perception, and quantitative evaluation.

## Evidence boundary

ROS1 navigation is a simulation result and physical TurtleBot work is team-based. Project 04 is a development workflow rather than an operational detector. Project 02 uses simulated regression data.
