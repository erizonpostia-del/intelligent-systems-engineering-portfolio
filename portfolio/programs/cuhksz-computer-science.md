## Programme connection and learning goals

My undergraduate background provided control, sensing and system-integration experience. Python and Linux projects showed how correctness depends on software architecture, testing, data interfaces and explicit evaluation protocols. I want to strengthen computer science fundamentals—particularly algorithms, software engineering, computing infrastructure and applied machine learning—and apply them to reliable AI-enabled systems.

The longer-term goal is to engineer solutions that connect models with users, data pipelines and operating systems, rather than only optimise an isolated metric.

## Evidence boundaries

The regression experiment is on synthetic data. The nine-waypoint ROS1 result is simulation-only; TurtleBot3 physical work was team-based; DQN was tested in FlappyBird-v0 rather than on the robot. The industrial vision project documents development validation and shared-server attribution limits, not a launched software product. These materials do **not** establish advanced distributed systems or commercial full-stack deployment.
