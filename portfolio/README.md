# Application reading guides — 2027 intake

**Technical portfolio of Jiang ZhengMeng** · Automation and Systems Engineering · Macau University of Science and Technology.

This directory helps readers jump to the **most relevant evidence**, not just the most relevant keywords. Each programme guide contains a short suggested reading order, a concrete connection to the area of study, and limitations of what the projects can demonstrate. The four project directories remain the canonical sources for code, figures, results, and attribution.
