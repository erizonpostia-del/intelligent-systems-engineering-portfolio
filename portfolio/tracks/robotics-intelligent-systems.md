# Robotics & Intelligent Systems

Suggested first-pass order for a reviewer interested in robotics, autonomous systems, and intelligent control:

1. [01 — Robotics & DQN](../../projects/01-robotics-dqn/) — ROS1 simulation, LiDAR handling, `move_base` waypoint control, team TurtleBot3 integration context, and controlled DQN evaluation.
2. [04 — Fire & Smoke Detection](../../projects/04-fire-smoke-detection/) — perception-system engineering, data governance, class-level diagnosis, and development decisions.
3. [02 — Machine Learning Evaluation](../../projects/02-ml-evaluation/) — explicit split logic, validation selection, and nested cross-validation.

This track shows a systems-to-perception-to-evaluation trajectory. Project 01 remains the primary robotics evidence; Project 04 is a computer-vision development workflow, not a deployed safety system.
